# Aseem Sharma

Personal site for Aseem Sharma (Lucky on GitHub), served by GitHub Pages from the repository root.

https://adminsharmasecureservicescausa.github.io/

## What’s here

A single static page: `index.html`, `css/site.css`, and `favicon.svg`. There is no build step. `.nojekyll` tells GitHub Pages to publish the files as they are.

The page replaces the unused [WebOps Club personal-website template](https://github.com/The-WebOps-Club/personal-website-template) this repository was forked from. The original MIT license remains in `LICENSE`.

```bash
python3 -m http.server 8765
```
